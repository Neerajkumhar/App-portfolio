# VISUARK — Interface Studies

A responsive React and TypeScript portfolio of five app interface studies across five industries. The site focuses on interface structure, accessible interaction, responsive layout, and store-faithful visual references.

## Projects

- BharatAgri — agriculture
- Coop — food
- Rowtine — crafts
- Catima — utility
- Hinge Arcade — gaming

Each case study uses locally stored official screenshots and app icons with visible source credits. The work is presented as interface study material and is not affiliated with or endorsed by the respective app owners.

## Stack

- React 19
- TypeScript
- React Router 7
- Vite 6
- Plain CSS

No backend, database, authentication, analytics, forms, or client-side image hosting is used.

## Getting started

```bash
npm install
npm run dev
```

Open the URL printed by Vite.

## Checks

```bash
npm run typecheck
npm run build
npm run preview
```

## Responsive behavior

The layout is built around a 1200px shell with fluid typography and spacing. Navigation, hero previews, project grid, About section, case-study galleries, contact cards, and footer collapse at smaller breakpoints. Motion is reduced automatically when `prefers-reduced-motion` is set.
